# Большой тестовый файл для обогащения данных

## 📁 Файл: `competitors_data_large.json`

Этот файл создан специально для тестирования модуля обогащения на **больших объемах данных**.

## 📊 Характеристики

- **15 конкурентов** на разных платформах
- **~400+ постов** (15-40 постов на каждого конкурента)
- **Размер файла:** ~0.4 MB
- **Платформы:** LinkedIn, VK, Telegram
- **Период:** последние 120 дней

## 🎯 Типы контента

Файл содержит разнообразные типы контента:
- Кейс-стади (case_study)
- Экспертное мнение (expert_opinion)
- Обновления продуктов (product_update)
- Образовательный контент (educational)
- События/вебинары (event)
- Интерактивные посты (interactive)
- Новости (news)

## 🧪 Как использовать

### Вариант 1: Через веб-интерфейс

1. Запустите сервер обогащения:
```bash
npm run dev --prefix apps/api
```

2. Запустите фронтенд:
```bash
npm run dev
```

3. Откройте форму → "Загрузить спаршенных данных конкурентов" → выберите `data/input/examples/competitors_data_large.json`

4. Нажмите "🤖 Обогатить"

5. Дождитесь завершения (2-5 минут)

### Вариант 2: Через API

```bash
curl -X POST http://localhost:3001/api/enrich \
  -H "Content-Type: application/json" \
  -d "{\"competitors_data\": $(cat data/input/examples/competitors_data_large.json)}"
```

## ⚠️ Важно

- **Время обработки:** 2-5 минут (это нормально для такого объема)
- **Стоимость:** ~$0.05-0.10 (зависит от модели)
- **Токены:** ~150K-200K входных, ~80K-120K выходных

## 🔄 Регенерация файла

Если нужно создать файл заново с другими данными:

```bash
node apps/api/generate-large-test-data.js
```

Скрипт автоматически сгенерирует новый файл с случайными данными.
