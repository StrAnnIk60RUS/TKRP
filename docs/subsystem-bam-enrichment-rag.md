# Приложение: подсистема БЯМ, семантического обогащения и поиска с подкреплением генерации

Материал предназначен для подготовки статьи по программному комплексу TKRP и тезисов по подсистеме работы с большими языковыми моделями, корпусом прецедентов и семантическим обогащением данных конкурентов.

**UML-диаграммы (PlantUML)** для публикации в PNG/SVG: каталог [`docs/uml/subsystem-bam/`](uml/subsystem-bam/). **Draw.io (курсовая):** [`курсовая/subsystem-bam-classes.drawio`](../курсовая/subsystem-bam-classes.drawio) — классы; [`курсовая/subsystem-components.drawio`](../курсовая/subsystem-components.drawio) — компоненты; [`курсовая/BD.drawio`](../курсовая/BD.drawio) — БД. Для импорта из PlantUML в draw.io — файлы `*-drawio.puml`. Инструкция — в [`docs/uml/subsystem-bam/README.md`](uml/subsystem-bam/README.md).

## 1. Таблицы базы данных

Логическая модель включает **7 сущностей** (как на рис. 3.2 пояснительной записки курсовой работы): `EmbeddingModelVersion`, `LlmModelVersion`, `SemanticEnrichmentSession`, `IngestionRun`, `Publication`, `ContentPlan`, `RagRetrievalLog`. Отдельная таблица метаданных корпуса не выделяется — глобальные параметры в реализации хранятся в файле `metadata.json` в каталоге `data/precedents`.

Ниже для каждой таблицы приведены атрибуты и их назначение. Вложенные JSONB-структуры, хранящиеся внутри полей таблиц, описаны отдельными подтаблицами.

### Описание компонентов

| Уровень | Компонент | Назначение |
| --- | --- | --- |
| Фронтенд | `useCompetitorsPipeline` | Управляет состоянием загруженной структуры данных конкурентов и процессом вызова семантического обогащения. Проверяет доступность серверной части и информирует пользователя о ходе операции, в том числе при частичном успехе отдельных пакетов запроса к большой языковой модели. |
| Фронтенд | `enrichmentService` | Клиент протокола передачи гипертекста для вызова операций обогащения, семантического поиска прецедентов и генерации черновика. Инкапсулирует базовый адрес сервиса и форматы тел запросов и ответов программного интерфейса подсистемы. |
| Фронтенд | `ProjectForm` | Оркестратор пользовательского интерфейса мастера проектирования контент-плана. Координирует шаг работы с конкурентами, поиск прецедентов, проверку готовности и запуск генерации черновика через клиентский сервис обогащения. |
| Бэкенд | `enrichmentRoutes` | Принимает запрос обогащения, проверяет ограничения размера входных данных и делегирует семантическое обогащение модулю обращения к большой языковой модели. При успешной нормализации инициирует сохранение прецедентов в корпус. |
| Бэкенд | `precedentRoutes` | Обеспечивает операции семантического поиска и получения сводки корпуса. Делегирует поиск и формирование сводки репозиторию прецедентов без дублирования прикладной логики в маршруте. |
| Бэкенд | `planRoutes` | Принимает запросы генерации чернового контент-плана. Выполняет поиск прецедентов с подкреплением генерации из базы знаний, передаёт контекст в конвейер генерации и возвращает клиенту контекст поиска, черновик, сведения о расходе ресурсов модели и метаданные генерации. |
| Бэкенд | `precedentRepository` | Центральный компонент слоя данных: сохранение прецедентов, гибридный поиск по векторным представлениям и лексемам, дедупликация, оценка надёжности кандидатов. Обеспечивает отложенное вычисление векторных представлений документов при поиске. |
| Бэкенд | `draftPlanGenerationPipeline` | Реализует двухэтапную генерацию структурированного ответа: построение каркаса плана и помесячное наполнение публикаций с опорой на сжатый контекст прецедентов. Выполняет постобработку и проверку итогового чернового контент-плана. |
| Бэкенд | `openrouter.js` | Единый клиент дополнения чата провайдера OpenRouter и оркестратор семантического обогащения данных конкурентов. Обеспечивает авторизацию, ограничение времени ожидания, учёт расхода вычислительных единиц модели и режим строго структурированного ответа. |
| Бэкенд | `embeddingService` | Клиент программного интерфейса векторизации текстов провайдера OpenRouter с разбиением входных строк на пакеты. Предоставляет функции косинусной близости и нормализации оценки для ранжирования при семантическом поиске. |
| Слой данных | `data/precedents` | Хранилище корпуса прецедентов, метаданных и журнала загрузки. |
| Слой данных | `data/runtime/api` | Оперативные снимки результатов программного интерфейса (черновики, промежуточное состояние мастера), вне корпуса прецедентов. |
| Внешний источник | `OpenRouter` | Внешний провайдер дополнения чата и векторизации текстов; настраивается через переменные окружения с ключом доступа и идентификаторами моделей. |
