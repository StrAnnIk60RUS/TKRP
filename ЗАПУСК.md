# Запуск TKRP из архива

Краткая инструкция для того, кто получил проект в ZIP (Git не нужен). Подробности для разработчиков: [docs/local-developer-setup.md](docs/local-developer-setup.md).

---

## Вариант A — Node.js и Python (основной)

### Что установить заранее

1. **Node.js** версии 20 или новее — [https://nodejs.org/](https://nodejs.org/) (LTS). Вместе с Node ставится **npm**.
2. **Python** 3.11 или новее — [https://www.python.org/downloads/](https://www.python.org/downloads/)  
   На Windows при установке включите **«Add python.exe to PATH»**.

### Шаги

1. Распакуйте архив в удобную папку (лучше путь **без кириллицы**, например `C:\Projects\TKRP`).
2. Откройте терминал в **корне** проекта — там должен лежать файл `package.json`.  
   В Windows: Shift+ПКМ в пустом месте папки → «Открыть в терминале» / PowerShell, либо откройте папку в редакторе и используйте встроенный терминал.
3. Выполните:

   ```bash
   npm run setup
   ```
4. Запустите:

   ```bash
   npm run dev
   ```

5. В браузере откройте: **http://localhost:5173**

**Если что-то не работает:** оставьте терминал с `npm run dev` открытым и посмотрите текст ошибок. Убедитесь, что ключ в `.env` указан без лишних кавычек и пробелов.

**Парсеры VK / LinkedIn** — по желанию: в `.env` можно задать `VK_COOKIE` и `LINKEDIN_COOKIE` (без них часть сценариев с внешними источниками может быть недоступна).
