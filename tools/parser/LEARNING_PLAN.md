# 📚 Полный стек для переписывания парсера на C#

## 1️⃣ Базовый уровень (C# fundamentals)

| Тема | Что изучать | Практика |
|------|-------------|----------|
| **Синтаксис** | Типы данных, операторы, циклы, условия | Переписать `main()` с консольным вводом |
| **Классы и структуры** | `class`, `struct`, поля, свойства (`get/set`), конструкторы | Создать DTO для поста VK (аналог `VKPost`) |
| **Объектно-ориентирование** | Наследование, полиморфизм, интерфейсы, абстрактные классы | Сделать интерфейс `IParser<T>` с реализацией для VK |
| **Коллекции** | `List<T>`, `Dictionary<TKey,TValue>`, `IEnumerable`, LINQ | Парсить список постов и фильтровать по дате/лайкам |
| **Обработка исключений** | `try/catch/finally`, иерархия исключений, кастомные исключения | Обернуть HTTP-запросы в свои исключения (аналог `VKParserError`) |

## 2️⃣ Работа с данными (JSON + парсинг)

| Технология | Зачем нужна | Практика |
|------------|--------------|----------|
| **System.Text.Json** / **Newtonsoft.Json** | Десериализация JSON из VK API | Создать классы `VkApiResponse`, `VkPostItem` и сериализовать/десериализировать их |
| **HtmlAgilityPack** | Парсинг HTML (если нужно брать данные с веб-страниц) | Написать парсер поста по ссылке, используя XPath/CSS-селекторы |
| **Regex** | Извлечение данных из текста | Парсить даты, ссылки, эмодзи из текстов постов |

---

## 3️⃣ HTTP и сети (самое важное для парсера)

| Технология | Зачем нужна | Практика |
|------------|--------------|----------|
| **HttpClient** | Асинхронные HTTP-запросы к VK API | Заменить `requests.get()` на `await httpClient.GetAsync()` |
| **IHttpClientFactory** | Правильное создание клиентов, rate limiting, retry policies | Настроить `AddRetryPolicy` для обработки временных ошибок VK API |
| **Cookies и авторизация** | Работа с токенами VK API (не хранить в коде!) | Создать класс `VkAuthManager`, который загружает токен из `.env` или secure storage |
| **Rate limiting** | VK API строго лимитирует запросы | Реализовать задержки между запросами, использовать `Polly` для retry с backoff |

## 4️⃣ Асинхронность (критично для производительности)

| Концепция | Зачем нужна | Практика |
|-----------|--------------|----------|
| **async/await** | Не блокировать UI/поток при запросах | Переписать все HTTP-запросы на асинхронные |
| **Task vs Thread** | Понимание, когда что использовать | Запустить 10 параллельных запросов к VK API и измерить время |
| **CancellationToken** | Отмена долгих операций | Добавить возможность отмены парсинга по Ctrl+C |

## 🗺️ Пошаговый план обучения (4–6 недель)

- [ ] Установить .NET SDK, создать проект `dotnet new console`
- [ ] Написать консольное приложение с вводом URL и выводом результата

- [ ] Добавить логирование (Serilog или NLog)
- [ ] Реализовать CLI-интерфейс (или сохранить консольный, как в Python)

## 🎯 Ключевые отличия Python → C# (на что обратить внимание)

| Python | C# | Примечание |
|--------|-----|------------|
| `requests.get()` | `await httpClient.GetAsync()` | Нужно явно указывать тип: `var response = await httpClient.GetAsync(url)` |
| `BeautifulSoup` | `HtmlAgilityPack + XPath/CSS-селекторы` | В C# нет магии — всё должно быть явным |
| `try/except` | `try/catch` | Нужно понимать иерархию исключений, кастомные исключения наследуются от `Exception` |
| Динамическая типизация | Статическая типизация | Все типы должны быть известны на этапе компиляции |
| `async/await` (простой) | `async/await` + контексты | В C# асинхронность сложнее — нужно понимать Task, CancellationTokenSource и т.д. |

## 📝 Примечания

- **VK API требует токена** — для работы парсера необходимо зарегистрировать приложение в [VK Developer Kit](https://dev.vk.com/) и получить `access_token`
- **Rate limiting** — VK API строго лимитирует запросы (обычно 300 запросов/сек с одного IP), поэтому обязательно нужно использовать retry policies с backoff
- **Безопасность токенов** — никогда не храните токен в коде! Используйте `.env` файл или secure storage (Windows Credential Manager, Azure Key Vault и т.д.)
